# User Guide

## Join a room

1. Open the room link.
2. Enter a name. Use the same name to return as the same player.
3. If the room is active, start solving.

Each room holds one puzzle. The admin starts the room before players can submit answers.

## Play

1. Click a cell to select a clue.
2. Type the answer letters.
3. Press Submit.

When the clue has no official answer yet, your guess waits for admin review. When the admin approves the answer, correct guesses score and the clue is marked solved.

You can press Reveal Answer to see the solution of an unsolved clue. A revealed clue gives you no points.
Reveal is disabled for clues you already solved.

## Points

Points depend on solve order for each clue:

| Situation | Points |
| --- | --- |
| First player to solve the clue | 2 |
| Later player to solve the same clue | 1 |
| Player who revealed the clue | 0 |
| Player who already scored the clue | 0 |
| Admin | 0 |

Rules:

- A clue scores only after the admin sets the official answer, or approves a submitted answer.
- The first player to solve sets the clue color.
- Each player scores a clue only once.

## Total score

Your total score is the sum of all points you earned in every room.
The total stays after a room finishes or is deleted.
The main page shows the lifetime score of every player.

## Colors

Each player gets one color:

| Order | Color |
| --- | --- |
| 1 | Red |
| 2 | Teal |
| 3 | Amber |
| 4 | Purple |
| 5 | Pink |
| 6 | Orange |
| 7 | Olive |
| 8 | Blue |

How colors work:

- Your name and color dot appear next to the room title.
- The Players list shows each player's color dot, name, and score.
- When you solve a clue, its cells fill with your color for every player.
- You see your own solved letters. For clues solved by other players, you see only their color.
- The color on the clue shows the first player who solved it.

## Admin role

The admin runs the room and does not play.

Admin tasks:

- Create and delete rooms.
- Set the official answer for each clue.
- Review pending submissions and approve or reject them.
- Start, pause, resume, finish, and close the room.

Admin rules:

- The admin has no player color and no score.
- The admin does not appear in the Players list.
- Setting the official answer does not solve the clue by itself. A player submission solves it. Waiting guesses that match the new answer are approved automatically.
- Approve scores matching guesses. Reject removes the guess and keeps the clue unsolved.
- Paused rooms accept no submissions.

## Rejected answers

When the admin rejects your answer, you see a short message on that clue.
The message disappears after a few seconds. Submit a new answer to try again.
